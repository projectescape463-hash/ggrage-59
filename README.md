# GARAGE 59

Концепт сайта независимого автосервиса. React, TypeScript, Vite.

## Запуск

```bash
npm install
npm run dev
```

## Публикация

Push в `main` запускает GitHub Actions и выкладывает сборку на GitHub Pages.

Сайт: https://projectescape463-hash.github.io/ggrage-59/

Цены, адрес и телефон в `src/data/` — демонстрационные.
